# browser-memory-agent

[![CI](https://github.com/abhiramvedipala/browser-memory-agent/actions/workflows/ci.yml/badge.svg)](https://github.com/abhiramvedipala/browser-memory-agent/actions/workflows/ci.yml)

Procedural memory for browser agents: record a multi-step web workflow once, store it in SQLite, and replay it later on pages whose DOM has changed by matching elements semantically. Work in progress; the full README lands in Phase 5.
